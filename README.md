# Salud MLOps — Unidad 2

Este repositorio mantiene un servicio académico que simula una categoría de enfermedad a partir de la intensidad, duración y cantidad de síntomas. El objetivo es gestionar sus cambios con Git y automatizar las pruebas y la publicación de la imagen Docker.

El código de la API, el simulador y el formulario estarán en la raíz del repositorio. Las pruebas estarán en `tests/` y el flujo de integración y entrega continua en `.github/workflows/`.
